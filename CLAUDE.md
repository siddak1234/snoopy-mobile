## Rules

1. Work only in this repository. A backend, web or deployment issue is a finding, not permission to edit a sibling: record it in the private `DESIGN-GAPS.md` ("Records") for a `snoopy-backend` session to file.
2. Preserve the frozen Nocturne UI: screens are composed from its components, `components/dialog.tsx` and the theme tokens; every size on the type scale, every press through `components/pressable.tsx` — `app/CLAUDE.md`.
3. Use theme tokens: no raw hex or ad-hoc font family outside `constants/theme.ts` (`audit:tokens`, `audit:type`).
4. Do not duplicate a Nocturne primitive; a new one only when none fits — `app/CLAUDE.md`.
5. Runtime network access goes only through `lib/platform/client.ts` and the generated `openapi-fetch` clients, with exactly the credential-less exceptions README "Runtime architecture" lists (`audit:platform`) — `lib/platform/CLAUDE.md`.
6. Credentials live only in `expo-secure-store`, this-device-only: never in AsyncStorage, a URL, route params, logs, fixtures or analytics. A webhook secret is shown once and stored nowhere, the Keychain included.
7. Never invent a field or workflow absent from the published contract. Follow the refusal map in `DESIGN-CONTRACT.md`.
8. Work goes through a branch, a PR, `all-green` and the owner's merge; the land step runs the change class's gate (`node scripts/change-class.mjs --run`) on the committed tree and CI's `all-green` runs the whole suite before a merge; each push runs the same class's gate (README "Verification"). `/code-review` every PR; `/security-review` anything touching auth, secrets, uploads, deletion or the billing link.
9. Billing follows ADR-0032 as `DESIGN-CONTRACT.md` (Round 16, 24.6, Billing) states it: no in-app purchase, the hosted checkout and portal on iOS only; the app's own billing rules are README "Runtime architecture".
10. Every screen uses the shared rules (`administers()`, `workspaceIfShown()`, `useIntentKeys()`, `refusalMessage()`, `withoutArchived()`, `deletionOutcome()`, `hostedAddress()`, `Pressable`, `heldAs()`, `addedAgainAs()`, `signedLink()`, `saveSignedFile()` and `shareSignedFile()` (behind `FileActions`), `Page`, `PageHeader`, `SectionTitle`, `Group`, the spacing table (`space`), `useAccessibilityTextSize()`, `StatTileRow`, `OpenRow`, `useRunDetail()`), never a copy — README "Runtime architecture".
11. Where a screen goes is proved under the real router (`__tests__/real-router/`) — README "Verification".
12. Every press has a test that presses it and asserts its outcome (`audit:presses`) — README "Verification".
13. No new documents. Documents of record here: `CLAUDE.md`, `README.md` and `DESIGN-CONTRACT.md`; this app's process records are private ("Records"). Supporting files: `docs/MAP.md` (generated), `docs/docs-map.json`, the folder `CLAUDE.md` files, `.claude/`, and GitHub's `SECURITY.md`, `LICENSE` (all rights reserved) and `.github/CODEOWNERS`. Findings and observations go into the private `DESIGN-GAPS.md`.
14. A fresh audit inspects the simulator or device and reports NOT OBSERVED, never PASS, for what it could not see — README "Verification".

## Gates and push

```bash
npm ci                      # only in a scratch clone (below)
npm run verify              # lint, the docs checks, types, every audit, contracts, tests, presses, facts (the full class)
node scripts/change-class.mjs  # this change's class and gate (--run runs it, --full forces the full class)
npm run audit:dependencies  # high or critical fails, but for scripts/audit-allowlist.json's dated exceptions; CI runs it, verify does not
npx expo-doctor
npm run export:ios
npm run export:android
git status --short
```

- Work only in a scratch clone outside ~/Desktop and iCloud: jest hangs on evicted files, and `.claude/hooks/guard.mjs` refuses installs and builds there. The guard also asks the owner first before a Write or Edit outside the scratch root and a project's memory, a Bash write into Downloads, Desktop, Documents or iCloud Drive, or an Artifact publish or delete (`../snoopy-backend/CLAUDE.md` rule 11); inside the scratch root it refuses any write outside a repository copy and a session's `docker-config` (row 10, the owner's "Strict one place", BUILD-PLAN 30.17), and the Stop hook shows the owner the loose files a turn left.
- One heavy gate at a time across agents (the session's gate lock); the land step is rule 8.
- `npm run hooks:install` once per clone: `.githooks/pre-commit` runs the private-data scan ("Test data") before every commit, and `.githooks/pre-push` the scan of the pushed commits, then the change class's gate (`scripts/change-class.mjs`), before every push; the classes are README "Verification". Never `git push --no-verify`.
- CI's `Deployed contract` job is red by design while the types run ahead of production: say so before pushing (`lib/platform/CLAUDE.md`).
- A PR is ready only when it is pushed, `all-green` passed on its head, and its body is final.

## Docs always updated

- Every change updates every doc and code comment that describes it, in one place each: link, never restate (the standard, section (e)).
- `docs/docs-map.json` maps code to its docs. `npm run check:docs` (in `verify` and CI) fails a code change whose doc did not change; a commit trailer `Docs-Unchanged: <reason>` exempts it.
- `npm run map` rewrites `docs/MAP.md`; `npm run audit:docs` fails a document naming a file that does not exist.

## Test data

- Tests, fixtures and docs use reserved values only: addresses at `example.com` (or a `.test` domain), phone numbers 555-0100 to 555-0199, IP addresses in 192.0.2.0/24, 198.51.100.0/24 and 203.0.113.0/24, and made-up names. Two exceptions, both the app's own text: a screen's example text (the `acme.co` placeholder) where a test asserts it, and a mailbox provider's domain, alone and never in an address, where the case is `lib/view/domain.ts`'s list.
- A client's name is never in a tracked file or a commit message; process records live only in the private backend ("Records").
- The kit's private-data scanner (`node scripts/kit/private-data-scan.mjs`) runs on every commit (`--staged`, `.githooks/pre-commit`), every push (`--push`, `.githooks/pre-push`), and in the change class's gate and CI (`--tree`). Its client-name pattern is CI's `CLIENT_DENY_PATTERN` secret, or `~/.config/autom8x/client-deny-pattern` on a machine, never this repository.
