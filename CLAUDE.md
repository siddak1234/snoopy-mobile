## Rules

1. Work only in this repository. A backend, web or deployment issue is a finding, not permission to edit a sibling: record it in `DESIGN-GAPS.md` for a `snoopy-backend` session to file.
2. Preserve the frozen Nocturne UI: screens are composed from its components, `components/dialog.tsx` and the theme tokens; every size on the type scale, every press through `components/pressable.tsx` — `app/CLAUDE.md`.
3. Use theme tokens: no raw hex or ad-hoc font family outside `constants/theme.ts` (`audit:tokens`, `audit:type`).
4. Do not duplicate a Nocturne primitive; a new one only when none fits — `app/CLAUDE.md`.
5. Runtime network access goes only through `lib/platform/client.ts` and the generated `openapi-fetch` clients, with exactly the credential-less exceptions README "Runtime architecture" lists (`audit:platform`) — `lib/platform/CLAUDE.md`.
6. Credentials live only in `expo-secure-store`, this-device-only: never in AsyncStorage, a URL, route params, logs, fixtures or analytics. A webhook secret is shown once and stored nowhere, the Keychain included.
7. Never invent a field or workflow absent from the published contract. Follow the refusal map in `DESIGN-CONTRACT.md`.
8. Work goes through a branch, a PR, `all-green` and the owner's merge; `npm run verify` is green before every commit. `/code-review` every PR; `/security-review` anything touching auth, secrets, uploads, deletion or the billing link.
9. Billing follows ADR-0032 as `DESIGN-CONTRACT.md` (Round 16, 24.6, Billing) states it: no in-app purchase, the hosted checkout and portal on iOS only; the app's own billing rules are README "Runtime architecture".
10. Every screen uses the shared rules (`administers()`, `workspaceIfShown()`, `useIntentKeys()`, `refusalMessage()`, `withoutArchived()`, `deletionOutcome()`, `hostedAddress()`, `Pressable`, `heldAs()`, `addedAgainAs()`, `signedLink()`, `shareSignedFile()`, `useAccessibilityTextSize()`, `StatTileRow`), never a copy — README "Runtime architecture".
11. Where a screen goes is proved under the real router (`__tests__/real-router/`) — README "Verification".
12. Every press has a test that presses it and asserts its outcome (`audit:presses`) — README "Verification".
13. No new documents. Documents of record: `CLAUDE.md`, `README.md`, `DESIGN-CONTRACT.md`, `DESIGN-GAPS.md` and `DESIGN-GAPS.archive.md`, and `docs/records/*`. Supporting files: `docs/MAP.md` (generated), `docs/docs-map.json`, the folder `CLAUDE.md` files and `.claude/`. Findings and observations go into `DESIGN-GAPS.md`.
14. A fresh audit inspects the simulator or device and reports NOT OBSERVED, never PASS, for what it could not see — README "Verification".

## Invariants

- The auth boundary is the root layout's `Stack.Protected`; nothing inside the tabs navigates to "/" — `DESIGN-CONTRACT.md` "Authentication and session".
- The app is not an OAuth client; its two documented variances are `DESIGN-CONTRACT.md` "Two documented variances".
- `app.config.js` refuses a preview or production build without the three pinned release values — README "Release configuration, pinned".
- `lib/generated/platform-contracts/` is generated and never hand-edited — `lib/platform/CLAUDE.md`.
- Mobile = web parity: every signed-in feature the website offers, on the same operations, in its words (ADR-0032) — `app/CLAUDE.md`.
- The owner's plain-words rule governs every screen's copy and steps — `app/CLAUDE.md`.

## Gates and push

```bash
npm ci                      # only in a scratch clone (below)
npm run verify              # lint, the docs checks, types, every audit, contracts, tests, presses, facts
npm run audit:dependencies  # CI runs it; verify does not
npx expo-doctor
npm run export:ios
npm run export:android
git status --short
```

- Work only in a scratch clone outside ~/Desktop and iCloud: jest hangs on evicted files, and `.claude/hooks/guard.mjs` refuses installs and builds there.
- One heavy gate at a time across agents (the session's gate lock). Commit, then run `verify` on the committed tree.
- `npm run hooks:install` once per clone: `.githooks/pre-push` runs `verify`, `audit:dependencies` and the salvage scan before every push. Never `git push --no-verify`.
- CI's `Deployed contract` job is red by design while the types run ahead of production: say so before pushing (`lib/platform/CLAUDE.md`).
- A PR is ready only when it is pushed, `all-green` passed on its head, and its body is final.

## Docs always updated

- Every change updates every doc and code comment that describes it, in one place each: link, never restate (the standard, section (e)).
- `docs/docs-map.json` maps code to its docs. `npm run check:docs` (in `verify` and CI) fails a code change whose doc did not change; a commit trailer `Docs-Unchanged: <reason>` exempts it.
- `npm run map` rewrites `docs/MAP.md`; `npm run audit:docs` fails a document naming a file that does not exist.
